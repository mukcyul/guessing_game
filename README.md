# Guessing Game (v1.0)
A simple guessing game made in Rust, following the book "[The Rust Programming Language](https://doc.rust-lang.org/book/)".
## How to run
1. Install the Rust development environment
([Link](https://www.rust-lang.org/tools/install))
2. Run the following command:
```
> cargo run
```
3. Play the game!
## How to play
You have 10 attempts. The program chooses a random number from 1 to 100. Upon writing a number, program let's you know if you got the number correct, if it's too big or too small. Upon guessing the right number - game closes. The same thing happens upon losing the game.
